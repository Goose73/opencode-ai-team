# Development rules

Use the native OpenCode V2 team; never simulate delegation by adopting role names.
Work inside this repository. Inspect scripts before running them. PowerShell scripts must support Windows PowerShell 5.1.
Keep at most two specialist tasks active and one writer per file. Specialists must not delegate.
Do not publish credentials, global configuration backups, private transcripts or unrelated project data.
Ask before public publishing, important deletion, privileged actions or global software installation.
Never use `--auto`. A shell approval is not permission to run unreviewed scripts.
Report real commands, exit codes and limitations. Mock tests do not establish live provider recovery.
